# UI and quality audit — 2026-10-24

Baseline: `main` at `8af246f` (live). After: branch `feat/site-upgrade`.
Measurements were taken locally against production builds (`pnpm build && pnpm start`) with
Playwright and Chromium. Lab numbers, not field data: they compare before and after, they do
not predict real visitors' experience.

## Measurements

Gzipped JavaScript referenced by each page (all chunks, including the legacy polyfill that
modern browsers skip):

| Page                                               | Before | After         |
| -------------------------------------------------- | ------ | ------------- |
| `/`, `/projets`, `/projets/portfolio`, `/a-propos` | 175 KB | 175 KB        |
| `/contact`                                         | 175 KB | 177 KB (form) |

Largest Contentful Paint and Cumulative Layout Shift, Pixel 7 emulation, 4× CPU slowdown,
1.6 Mbps / 150 ms latency, median of 3 runs:

| Page                 | LCP before | LCP after | CLS before | CLS after |
| -------------------- | ---------- | --------- | ---------- | --------- |
| `/`                  | 708 ms     | 860 ms    | 0.0005     | 0         |
| `/projets`           | 688 ms     | 808 ms    | 0.048      | 0.041     |
| `/projets/portfolio` | 716 ms     | 868 ms    | 0.031      | 0.037     |
| `/contact`           | 664 ms     | 772 ms    | 0.093      | 0         |

- The LCP cost (+100 to 150 ms) comes from the render-blocking stylesheet growing from 5 KB to
  8 KB gzipped. LCP elements are text (the headline or summary), never an animated element:
  an early version animated them and pushed LCP to 1.4 s on two pages; this was fixed.
- Screenshots are pre-optimised WebP (13 to 57 KB), lazy-loaded below the fold, with
  intrinsic dimensions: no layout shift from images.
- INP was not measured (no field data, little interactivity).

## Verified by the test suite

74 tests pass against the production build without an e-mail provider (as in the Docker
image), and 18 contact tests pass against the mock provider (desktop + mobile projects).
Covered:

axe (WCAG 2.1 AA) on every page, no browser console errors, no CSP violation on any page,
every visible image has alt text and dimensions and loads, reduced motion disables every
animation, 404 status for unknown projects (first request, direct, client-side), contact API
(origin, content type, size, malformed JSON, validation, control characters, rate limit,
honeypot, unconfigured provider), contact form (client errors with focus management, honest
failure message, success and provider failure against a mock provider).
